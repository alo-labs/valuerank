# Coding Agent ValueRank - Agent Profiles

Last updated: July 28, 2026

## Claude Code

Claude Code holds the top AA Index row with Opus 5 (max) and several other Opus 5 / 4.8 settings near the quality frontier. Opus 5 (high) is the strongest Claude Code Overall finisher because it keeps most of the Index while cutting cost versus max. Opus 4.8 still benefits from official TB2.1 coverage (78.9%); Opus 5 does not yet, so it takes neutral TB2.1. GLM-5.1 remains the weakest covered TB2.1 Claude Code family (58.7%).

## Codex

Codex dominates the Overall top 10 in this refresh. GPT-5.6 Terra (max) is the value leader with both strong AA Index and TB2.1 coverage (78.4%). GPT-5.5 (xhigh) still has the best TB2.1 accuracy mapped into the cohort (83.1%). GPT-5.6 Sol variants lead or near-lead the AA Index but are TB2.1-neutral. Luna variants are cheaper with solid Index and TB2.1 (75.7%).

## Cursor CLI

Cursor CLI remains the cost-efficiency story via Composer 2 / 2.5, and still fields GPT-5.5 / GPT-5.4 / Opus 4.7 medium rows. None of the current Cursor CLI AA rows have a family-level TB2.1 match (the official board's Cursor CLI + Grok 4.5 row is outside this AA cohort).

## Opencode

Opencode + Opus 4.7 (medium) remains in the cohort as a mid-pack AA Index / mid cost row without TB2.1 coverage.
