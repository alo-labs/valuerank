# NZ egg-market project

This is an auxiliary market-structure project kept separate from the ValueRank ranking pipeline.

- `market-structure/build_market_structure_pdf.py` generates the selected A3 infographic PDF.
- `market-structure/nz_egg_market_structure.pdf` is the retained final render.
- `source-corpus/` contains local source documents used during research; it is ignored because it includes licensed and potentially confidential material and should not be staged by default.
