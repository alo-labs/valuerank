# Scope — DR-SCOPE

**Question.** What consumer AI chat subscriptions expose allowance meters, and which apps track a subscriber's allowance, local usage estimate, API spend, or crowdsourced plan reports?

**Mode.** Ultradeep by user request: the topic is date-sensitive, user reports conflict, plans and feature surfaces differ, and the desired artifact requires evidence provenance.

**In scope.** Perplexity, xAI/Grok, Mistral Le Chat, DeepSeek consumer chat, Poe, Meta AI, the Google Gemini app, and standard ChatGPT (non-Codex). Tracker discovery includes provider meters, third-party account readers, local estimates, API-cost/usage tools, and crowd submissions.

**Date rule.** User-report publication dates must be 2026-09-05 through 2026-10-05 inclusive. Publication date and reported observation interval are separate. Official policies and product documents are current context, not user-measured datapoints.

**Out of scope.** Claude (separate workstream); ChatGPT Work/Codex quota values; Gemini CLI/Antigravity; coding-only Vibe/Grok Build reports as chat usage; enterprise/workspace allowances; API billing as consumer plan usage. Any Codex quota value may use only TiboTattle's homepage; this package reports no Codex allowance number.

**Success criteria.** Keep app discovery separate from actual quota meters, local estimates, API cost estimators, and crowd reports; cite all material claims; record executed searches; identify each user-report author's exact tier or say “not stated”; preserve unsupported/inconsistent reports as qualitative; validate JSONL references and report citations; document gaps.

**Assumptions and limits.** Public posts are self-reports unless otherwise stated. A product's own listing or README can establish its own stated capability, not independent accuracy. No access to private or login-gated data is assumed.
