# Adversarial critique — three Ultradeep cycles

Each cycle used the four SB angles: steelman, contradiction hunt, missing stakeholder, and failure mode. These are documented review passes by the task agent; they are not represented as independent reviewer sign-off.

## Cycle 1 — exact identity and plan transfer

**Steelman:** A consumer might reasonably treat a family name or a retired API alias as equivalent to the current model with the same vendor label. **Contradiction hunt:** DeepSeek's dated release note says the retired `deepseek-v4-flash` model name now routes to V4.1 Flash, while OpenCode still shows distinct V4 Flash and V4.1 Flash rows with different Go caps. Z.AI also redirects GLM-5.2 plan requests to GLM-5.3. **Missing stakeholder:** A ValueRank reader needs the benchmark's exact model ID/effort, not only a current provider's family-level phrase. **Failure mode:** Choosing the legacy V4 Flash allowance could misprice the V4.1 backend, or conversely transfer an unrelated sibling limit.

**Loopback and repair:** The direct API alias notice does not establish the target behind a third-party subscription catalog row. The six V4.1 Flash rows previously associated with the V4 Flash roster ID were removed from qualified candidates. The roster row is now marked uncertain with no selected route; eight OpenCode/Ollama catalog tier rows remain in `route-exceptions.csv` with API-equivalent value not computed for this roster variant. Z.AI GLM Coding Plan is not counted for the GLM-5.2 roster row because its documentation redirects that request to GLM-5.3.

## Cycle 2 — allowance comparability and hidden denominators

**Steelman:** A weekly credit count, a 20× plan label, or a team usage pool may appear sufficient to compare if converted with a broad API price. **Contradiction hunt:** OpenAI/Codex evidence allowed only the TiboTattle homepage, which showed a checking state; Kimi publishes relative agent-credit multipliers without a token denominator; Alibaba describes dynamic model/token/reasoning/tool credit charges without a Qwen3.8 Max coefficient. Z.AI, by contrast, publishes model multipliers and an explicit formula. **Missing stakeholder:** Individual users and shared Team seats do not consume a common amount per subscription. **Failure mode:** A guessed average would create a fake universal token allowance and could divide shared credits as if each seat received the whole balance.

**Loopback and repair:** OpenAI/Codex, Kimi membership, Alibaba's Qwen credits, and percentage-only chat allowances are either excluded from the ranking or described with their exact missing denominator. Z.AI is converted only with its official formula and model-matched API tariff. Ollama Team is explicitly labeled shared; API-equivalent values are shown as a total shared pool, not per seat. No user-reported numeric allowance is used as a plan denominator.

## Cycle 3 — time dependence, cadence, and global claim

**Steelman:** One comparison value per model is easier to read and could suggest a stable cheapest provider. **Contradiction hunt:** Z.AI credits have peak/off-peak behavior, an active all-day 50% campaign ending 2026-10-07, and an additional GLM-5.3-Flash overnight campaign. Its current page did not expose the official quarterly fee even though quarterly billing is documented. **Missing stakeholder:** A user may work primarily off-peak, be region-ineligible for a model, use long contexts, or share a Team balance. **Failure mode:** Treating a short campaign as recurring or inferring a quarterly fee could reverse a route ranking.

**Loopback and repair:** The table displays peak-only and all-off-peak Z.AI scenarios and a separately dated current campaign value; it does not stack or annualize the extra Flash campaign. Quarterly Z.AI allowance rows stay visible, but the missing fee and value multiple are blank. Grok/Luna context brackets, Muse Spark region eligibility, and Team shared usage are called out. “Best quantified route” replaces any universal “global cheapest” claim where a competing denominator remains opaque.

## Residual deltas and stop decision

- **Medium, identity gap:** The DeepSeek legacy direct API name is routed to V4.1 Flash, but OpenCode does not disclose the backend behind its separately listed V4 Flash subscription row; the exact route stays unselected rather than inheriting a V4.1 allowance.
- **Medium, temporal risk:** Z.AI's current promotions end October 7; the snapshot route may change shortly after cutoff.
- **Low, denominator gap:** Z.AI quarterly price, Alibaba Qwen credit coefficient, and unquantified consumer plan quotas remain unavailable in the inspected sources.
- **Low, coverage gap:** The quantified routes cover three providers only; other exact-model subscriptions remain unranked when their allowance denominator is not comparable.

No high-severity unsupported calculation remains in the package. Automated source/citation/claim validators and parent review are pending and are not represented as passed.
