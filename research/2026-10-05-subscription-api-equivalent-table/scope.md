# Scope

## Research question

For each exact model ID in the 25-model ValueRank roster, identify the lowest effective-cost subscription provider and route only where the exact variant and an API-pricing-comparable monthly allowance can be evidenced. Show every relevant paid tier and billing cadence for a selected provider, including price, allowance, API-equivalent usage, source class, and exact direct source links.

## As-of date and unit of analysis

Research and plan/API-price snapshot: 2026-10-05. The unit is a model-specific paid route, not a provider family. Exact IDs and benchmark efforts come from the current project roster. The effort value is retained as roster metadata; it is not silently transferred to a subscription entitlement.

## In scope

- All 25 exact IDs and efforts from the current roster, including primary-ranked and source-only rows.
- Current first-party plan prices, billing terms, exact-model access labels, published allowance denominators, and relevant API token rates.
- Public research packages dated for the 2026-09-05 to 2026-10-05 user-report window; individual reports are not used as plan denominators unless comparable, and no numeric user report was used here.
- Three transparent model-token mix profiles, plus separately labeled time-of-use and limited-date campaign scenarios.
- Machine-readable coverage, every qualified candidate tier, direct source links, evidence, claims, unknown reasons, and validation status.

## Out of scope

- Treating a user's quota percentage, request count, or anecdote as fixed tokens without a model, exact plan tier, workload mix, and denominator.
- Ranking a paid plan with opaque credits, relative multipliers, or account-level utilization as if those were API dollars.
- Transferring API rates, plan prices, entitlements, or allowances between sibling variants. An explicit provider-documented one-to-one alias is recorded as such and its target route is used.
- Inferring annual prices, quarterly prices, API pricing, currency conversion, or plan entitlements where current official evidence does not state them.
- A universal market census. The selected provider is the best qualified route found, not proof that no unquantified competitor is cheaper.
- HTML or PDF outputs.

## Success criteria

All roster IDs appear once; every selected route has an exact-model identity record, published subscription denominator, published API tariff, cadence and fee; all paid tiers/cadences of selected providers are retained; API-equivalent values are profile-dependent; unknown denominators stay not computable; each claim links to evidence and each evidence record to sources.
