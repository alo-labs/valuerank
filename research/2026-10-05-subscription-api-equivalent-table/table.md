# Subscription route and API-equivalent comparison

**As of 2026-10-05.** This table includes every exact roster ID and effort. A selected row means the highest API-equivalent value per effective monthly fee among the exact-model routes with a published, comparable denominator that were found. It does not establish a universal market minimum when another provider has exact-model access but no convertible allowance.

Value multiple = monthly API-pricing-equivalent allowance ÷ effective monthly subscription fee. Lower subscription cost per US$1 of API-equivalent usage is the inverse of that multiple. API-equivalent dollar amounts and token totals depend on the three workload profiles in [methodology.md](methodology.md).

## Reading the table

- “Best quantified” is deliberately narrower than “global cheapest”: opaque account plans, unverified routes, unsupported variants, or missing conversion denominators are excluded from the ranking and named in the row notes.
- OpenCode publishes per-model dollar use limits and matching token rates. Ollama publishes dollar usage credits and matching model rates. Z.AI publishes credit quotas, a model-specific credit formula, and separate API rates; its token result depends on profile and schedule.
- A provider's account-level percentage, a request-count estimate, or a user's isolated usage report is not treated as a token allowance without the exact tier, model, workload mix, and denominator.
- Current campaign values are shown as a dated scenario. The Z.AI all-day half-credit offer ends 2026-10-07; the separate Flash campaign is not stacked or annualized.
