## Profile ordering and time basis

API-equivalent USD is a route-price value for the monthly allowance. Token envelopes are P1 / P2 / P3 respectively; DeepSeek route token envelopes display peak / off-peak because those providers publish different rates by time. Z.AI baseline multiples use its standard full-rate credit formula. A fully off-peak Z.AI schedule consumes half the normal credits and doubles profile token/API-equivalent totals; mixed schedules require the actual peak/off-peak work share. During the 2026-09-25 through 2026-10-07 all-day offer, the 50% rate applies all day. The separate 23:00–09:00 Singapore GLM-5.3-Flash campaign is documented in the selected model note and is not combined with this table's monthly token envelope.
