# Research plan

## Mode and source budget

Ultradeep applies because the request asks for a recent, source-constrained empirical check plus a broad tracker-app landscape, with three adversarial review cycles. The phase contract sets a preferred source budget of 30 and configured maximum of 40. The preserved inventory has 37 URL records, exceeding the preferred budget by seven while remaining below the configured maximum. The excess preserves the existing audit trail and adds bounded app coverage; search-result pages and discovery-only sources are never counted as factual support.

## Retrieval strategy

1. Open the canonical https://tibotattle.com/ using Codex built-in web__run; inspect only the public homepage for Codex crowdsourced numeric allowance values and visible sample details.
2. Apply the 2026-09-05 to 2026-10-05 inclusive cutoff to empirical allowance reports. Do not count product release dates or page update dates as user allowance reports.
3. Use TiboTattle documentation and privacy disclosures to describe publisher-stated chart definitions, participation, provenance, and sample limits; attribute them to the publisher.
4. Discover adjacent tools from direct product, documentation, privacy, repository, app-store, and official help pages. Record capabilities and measurement class only.
5. Use search results and community posts for discovery, not factual or numerical support. Preserve the direct TiboTattle Reddit post as discovery-only; exclude every quantity in it.
6. Cross-check claims against evidence IDs, distinguish first-party publisher claims from independent user data, and explicitly mark pages whose content was loading or inaccessible.

## Planned source classes

- Primary: TiboTattle homepage/docs/privacy; tracker publisher pages, repositories, and app-store listings; OpenAI help guidance.
- Secondary: direct developer-community product-discovery post.
- Portal/tertiary: search-result artifacts, retained for reproducible discovery only.

## Analysis and critique

- Map each report claim to one or more evidence IDs and source IDs.
- Keep the homepage retrieval state, its chart definition, and privacy caveats distinct.
- Conduct three cycles: skeptical evidence review, methodology/measurement review, and red-team scope/attribution review. Each cycle records steelman, contradiction hunt, missing stakeholder, failure mode, severity, and loopback.
- Run report-format, citation, claim-support, and phase-gate validators; save raw outcomes in validation/.

## Known limitations before retrieval

- Public chart content may load asynchronously and can change after the access date.
- Some tracker features are self-described and cannot be independently tested without installing software or connecting accounts.
- Search and App Store discovery are not exhaustive.
- An absent public value in a page capture does not show that no value existed at any earlier or later time.
