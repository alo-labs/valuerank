But the Coding Agent Index component — 16–74% of basket cost in the max-effort ranking — is by the draft's own words "the agent's pay-per-token API cost," i.e. an agent-workflow API-token cost (AA's methodology defines it as the average pay-per-token API cost per task from provider token pricing, with cache rates taken from live measurements rather than the run itself ). The charge-class boundary record is accurate, but the single headline label blurs two different measurement objects: model-evaluation tokens (AA Index runs) and vendor-agent workflow tokens.
