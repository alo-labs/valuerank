## 1. Findings by severity

**Critical**

- **The Plan half of the objective currently yields zero supportable claims, and no part of the read text identifies a public-data path to the first identified M_W.** Per part 1, 0 of 30 and 0 of 74 plan rows have an empty flag list, and per parts 4–5 the Plan score is API cost ÷ an unidentified multiple that is, at best, an observed-workload figure whose identification on W is blocked by a chain: E210 is inactive until AA publishes a cache split, E319 requires a capacity solver to exclude other binding constraints under data nobody publishes, and O19 bars analyst-assumed allowances from intervals. The objective unequivocally serves Plan buyers "ranked separately"; what ships is labelled "exploratory arithmetic". Recommended change: Publish a Plan-claims blocker ledger per (model × plan) cell naming the single unsatisfied gate (cache-split region, capacity-solver evidence, concordance failure, basis unrecorded), and commit to the cheapest structural unblock: derive the basket's per-category demand bounds empirically from the basket's own measured run data (AA publishes per-task cost and per-suite tokens; a formatter/effort-level token ledger would bound ρ_k) rather than waiting on AA's Index-wide cache split — implementable from public data if the per-evaluation token fields are captured. Absent this, the Plan basis may remain exploratory indefinitely with no visible exit.

**High**

- **21 of 30 and 60 of 74 plan rows are anchor- and interval-ineligible solely because their valuation basis "is not recorded" (E138/E170 outcome 4).** This is bookkeeping, not an evidence gap: the SemiAnalysis routes were transcribed at selection (2026-10-07) against an implicitly dated price list, and part 5's price-record registry (≤7 days at V, E216) holds the tariffs needed to pin a basis retroactively. Outcome 4 makes a row "ranked, flagged, anchor- and interval-ineligible" — so the single largest flag class on Plan rows is self-inflicted. Recommended change: a one-time backfill assigning each measured and ceiling route the provider price list in force at its measurement/selection date, re-run through the E170 gate, with any route that cannot be re-based reclassified explicitly rather than silently carrying outcome 4. This removes one flag class from 21/60 rows at zero evidence-collection cost.

**Medium**

- **Owner decision challenge (O24).** New argument, distinct from the settled "overlap disclosed" point: the basket prices Terminal-Bench 4.0 twice (AA Index run plus its 66 tasks inside the Coding Agent Index's pooled cost), so C_W sums two concurrent deployments — bare model and vendor agent — of identical tasks. The headline's claim is "lowest cost for the value it delivers in practice," and no single practice runs both deployments; the double-priced dollars are currently disclosed only verbally ("the overlap is disclosed", part 3), not quantified per row. Recommended change: quantify the per-row dollar overlap (the TB 4.0 Index cost, since the pooled share is inseparable) as a numeric column in the disclosure, and publish a labelled single-deployment bridge (basket minus the TB Index-run component) as a diagnostic. Keeps O24 intact for scores.
- **Owner decision challenge (O152, ranks primary).** New argument: in the AI Coding Daily ranking, 0 of 19 adjacent API ranks are separable, yet the ordinal positions 1–20 remain the primary display object. Whatever the separability footnote says, a 20-row ordinal ordering materially overstates discrimination to the headline reader; the exchange-rate and value-variance disclosures don't touch this. Recommended change: make the noise band the primary visual unit of the ranking table (grouped rows, band labels first), with the ordinal rank retained inside each band per O152. Ranks stay; the display stops implying order the method itself cannot establish.
- **Frozen a4 anchors contradict current completeness rules for the three Claude Opus 5.5 rows.** Part 4 states those rows became complete under O175 (2026-11-03) but "stay out of the anchor references until the next versioned re-freeze", with no scheduled trigger. Meanwhile the published exchange rate and E60 cost-influence figures are computed from references that no longer match the rule as written, and the read text does not say whether the E187/E205 rebuilt-anchor diagnostics now include them. Recommended change: publish a counterfactual "a5-candidate" anchor object each release (references = all rows eligible under current rules), with exchange rate and rank deltas, and a defined re-freeze trigger under O120 when the candidate moves any row across an anchor.

**Low**

- **Separability threshold omits cost noise entirely, although a rounding-interval floor exists.** SD_i uses analytic quality SD only; AA chart totals rounded to USD 1 are already treated as rounding intervals (part 3), which induces a documented minimum cost dispersion the threshold could include as a conservative floor — partially offsetting the acknowledged downward bias instead of disclaiming it. Low because E340's disclosure is honest.

Recommend publishing the unclipped pooled value alongside as a sensitivity. Low.

## 2. Methodology design recommendations

1. **Valuation-basis backfill** (see High): registry field `valuationBasis = (priceListID, inForceDate)` per Plan route, populated from the ≤7-day price-record registry at the measurement or selection date; re-run E170; report the delta in outcome classes.
2. **Plan blocker ledger + empirical demand region**: per cell, the named unsatisfied gate; plus a capture of per-evaluation token counts by category where AA exposes them, to bound ρ_k for basket categories without waiting for AA's Index-wide cache split — this directly unblocks E210.
3. **Counterfactual anchor object** (a5-candidate) published each release with frozen-reference and current-rule-reference panels side by side, exchange-rate delta, and rank deltas on both bases; adoption only via O120's versioned re-freeze.
4. **Band-primary table rendering** (with ordinal ranks retained inside bands) for the two leading rankings; keep the common-leaf ranking's table unchanged since it earns no claims anyway.
5. **Cost-noise floor in separability**: add uniform rounding noise from published rounding intervals to each row's SD before the pairwise threshold; publish the threshold both ways for one release to show the direction.
6. **Agent-stack transparency**: print each max-effort row's Coding Agent Index share s_i (16–74%) as a displayed column, not only in scores.json, and log a dated data request to AA for a model/agent token split and per-sub-benchmark costs (which would also make the SWE-Atlas QnA share — currently ~43% under an equal-task-cost assumption — measurable rather than labelled).
