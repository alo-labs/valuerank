**Medium**

1. **The E177 swing-attribution release gate is structurally blind to admission and exit rows.** The Governance section states: "The gate compares rows ranked in both releases; a row ranked only in the new release is published as 'cohort admission (no prior score)' and one ranked only in the old release as 'cohort exit', and neither is held by this gate." This is now a materially wider hole than when it was first decided, because O145 (retaining a configuration one release after it leaves the frontier/near gap) creates recurring, scheduled churn: the part-17 cohort record shows twelve configurations newly retained and several new admissions in one release. A family can therefore appear, swing, and exit within the eternal-blind spot — an evidence mis-join or wrong-leaf-selection error on a newly admitted row never faces the only gate that can *hold a release* for an unexplained movement (the existing mitigations — clip gate, Index reconstruction residual, O182/O183 like-for-like checks — test cost plausibility and frontiers, not the quality side or the composite movement). Recommended change: for each admission row, compute a shadow prior from the closest surviving same-family configuration (or its O121 common-leaf value) and print the admission's against-shadow delta; a delta above a set threshold (say 5 points) does not hold the release but must name the causing bundle fields, mirroring E177's >5-point naming requirement.

2. **Review convergence (O56/O205) has no round-scope freeze, so a "round" can span different draft states.** These parts define a clean round as one raising no Medium-or-higher finding, but the review protocol splits one model's reading across multiple sectional passes (17 parts over multiple sessions, as this very review). If the draft is amended between a model's part-3 pass and its part-15 pass — which happens under "a non-clean round being answered with a new draft" — some of the model's findings address one draft state and others address another, so neither "clean" nor "non-clean" is well defined for the round, and a later part's finding could already have been pre-empted (or created) by a mid-round amendment. Recommended change: record in the ledger, at each round's start, the draft ref/SHA and the part list the round covers; a round counts as clean only if all its passes ran against that ref, else the remaining parts are re-read on the new draft before the round is scored. This is governance rather than ranking math, but convergence is the draft's stated quality-assurance endpoint, so I place it at Medium.

**Low**

1. **Row-level scenario dispersion (E87) is silently cost-only for range-carrying rows.** O114 directs scenario frequencies to draw an O94/O196 row at its published cost, so for exactly the rows carrying a registered cost-range ([C, factor×C] or wider blocker hulls), the published Var_s(V_i) reflects quality dispersion alone while the row visibly carries cost uncertainty — a reader comparing dispersions across rows will misread a flagged-caveat row as well-measured. Recommended change: print the E87 dispersion beside a marker "published-record cost draw (O114); interval outputs read the range" for any row in an O170 outcome-3/-4, O94/O98 or E196 hull state.

2. **The two-ranking τ_b floor of eight shared configurations (E288) is near-vacuous in practice.** Part 17 reports the check "undefined (panel too small) on a panel of 4"; with the rankings at 9 and 20 rows of a 37-configuration cohort near-maximal overlap is ≈ 9, and the first v3 release reached 4. Two added arguments beyond the settled threshold itself: (a) at small panels the estimator's precision is the binding problem, not just existence — empirical work suggests roughly 24 pairs are needed for a τ_b of 0.7 to carry a usable 95% interval width, and small-τ estimates near small samples behave like random signals; (b) the leading rankings share leaves only partially by design, so the shared panel may never reach 8 without intervention. Recommended change: publish the O121 common-leaf ranking's τ_b against each leading ranking over its (larger) matched panel as a descriptive check, and preferentially register configurations eligible for both rankings when O145 retention and effort selection allow a choice. [pmc.ncbi.nlm.nih](https://pmc.ncbi.nlm.nih.gov/articles/PMC11148401/)

3. **The 15-minute schedule grid (E39) has no refinement sensitivity.** Capacity is certified as a point only when lower and upper bounds coincide, but both bounds are computed on the same grid; quantization error (bursts aligned to reset boundaries) can move a certified λ without any test in the release-test list. The release tests cover burst-timing feasibility on a fixed grid, not across grids. Recommended change: a low-cost diagnostic that re-runs the feasible-capacity LP on a 5-minute grid and publishes the capacity delta per route; certify points only where the delta is under a named tolerance.

## 2. Methodology design recommendations

1. **Admission/exit shadow-delta gate** (implements Medium-1). For each row released as "cohort admission", build a shadow comparator \(S_i^{\text{shadow}}\): prefer the ranked prior-release configuration of the same family (nearest effort by the variation ordering), else the row's value on the O121 common-leaf workload. Publish \(\Delta_i = Q̄_i - Q̄_{\text{shadow}}\) in scores.json (`diagnostics.admissionDeltas`); any \(|\Delta_i| > 5\) points must name the changed bundle fields, matching E177's existing naming contract. Cost: one added join on data already bundled. This closes the only release-hold blind spot without touching owner weight policy.

2. **Convergence round-scope records** (implements Medium-2). One ledger line per round: round id, draft SHA, parts covered, passes run. Build-tool absence needed; this is process-only and cheap, and it makes O205's "real defect restarts it" testable — a finding's repeat/settled status depends on which draft state it reviewed.

3. **Common-leaf cross-ranking agreement series.** With the two leading rankings structurally disjoint (4 of a possible 9 shared today), the published cross-check should run where panels exist: τ_b of the O121 common-leaf value order against each leading ranking's API-value order over its matched panel, with the bootstrap and cluster-bootstrap companions already built for E62, and interval widths printed (small-panel τ estimates need widths reported explicitly ). [pmc.ncbi.nlm.nih](https://pmc.ncbi.nlm.nih.gov/articles/PMC9326300/)

4. **Grid-refinement diagnostic for the capacity solver** (implements Low-3). Deterministic, off-scored: run the E39 time-indexed LP at 15 and 5 minutes, publish `capacityGridDelta` per route; a point certification (lower = upper under recorded semantics) additionally requires the delta below tolerance. This is structurally identical to, and the engineering of uncertainty bars for capacity.

5. **RNG environment pinning.** The draft already records the drawing Python version beside the seed — correct, since CPython only guarantees `random()` itself across versions and derived samplers (e.g., Beta in the now-Jeffreys S1T draws) are version-fragile. Two cheap hardenings: pin the scenario build to a container image or `uv`/`requirements` lock in CI, and record a hash of the `random` module source actually used in `scenarios.generator`, so a same-version ABI rebuild or vendored stdlib is detected. [docs.python](https://docs.python.org/3/library/random.html)

6. **E87 dispersion cost-exclusion marker** (implements Low-1): add one derived boolean (`costDispersionExcluded`) read from the row's valuation/caveat state, rendered beside the printed dispersion. No new statistics.
