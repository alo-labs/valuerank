**Medium**

- **The Coding Agent Index cost is imputed with a one-sided bias risk.** O27 defines cost as the pooled per-task-attempt average excluding missing telemetry × 290 tasks (v2.0). If missing telemetry correlates with expensive tasks (timeouts, long agentic runs), the row's cost is biased low — a systematic, one-directional error entering a 25%-weighted score and the anchors, only partially handled as "cost precision" in the scenario layer. AA does publish per-task cost, token usage and execution time, so the sensitivity is computable from public data. Concrete change: publish a one-sided sensitivity for every row with excluded telemetry — impute the missing tasks at the row's own observed maximum per-task cost, and at the cohort's 75th-percentile per-task cost — reporting the value-rank change on both bases as a diagnostic. [artificialanalysis](https://artificialanalysis.ai/methodology/coding-agents-benchmarking)
- **The separability threshold omits cost noise and fixes ρ = 0 as an assumption, when public data can bound both.** Part 1 states no public cost SD exists and the correlation sign is an assumption. But AA reports cost per task per configuration, and Bug Hunt Bench publishes every individual run — score, time, cost and turns — in `results/runs.csv`, with per-configuration spread documented in its variance caveat. Bug Hunt's own maintainer documents large run-to-run effects (e.g., GPT-6 Astra (max) rising from 45 to 55 over 3 runs), a component E155 excludes from every stream. Why it hurts: separability (2 of 7 and 0 of 19 adjacent ranks today) is the draft's main honesty instrument, and it rests on an approximation the draft itself says has an unestablished net direction. Concrete changes: (a) where per-task costs are public, propagate a lower-bound cost SD into the threshold — SE(C) = √(Σₜ Var(cₜ)/aₜ) over tasks t with aₜ attempts, converted to the value scale via the anchor slope SD = 0.25·100·ln2/ln(c_H/c_L)·SE(C)/C, and combined in quadrature with the existing 0.75·SD_Q term; (b) estimate ρ empirically from Bug Hunt's run-level outcomes (within-configuration cross-run agreement per task) and publish measured values beside the assumed 0/0.3/0.6 grid where the data allows. [artificialanalysis](https://artificialanalysis.ai/methodology/coding-agents-benchmarking)

## 2. Methodology design recommendations

1. **Plan-evidence burn-down + mandatory valuation-basis intake** (from the High finding). Data source: existing `scores.json planRows[].flags` plus `data/plan_reports.json`; add `valuation_basis` as a required admission field, validated against E170's price-record join at intake. Output: a per-release table of flag counts by kind, joint flag distribution, M_W-identified share, and a release-over-release delta, published beside the Plan outputs.
2. **Cost-noise lower bound and empirical ρ for separability.** For each row priced on a component with public per-task costs, compute SE(C) = √(Σₜ Var(cₜ)/aₜ); convert to the value scale with the anchor exchange-rate slope; add to the threshold 1.96·√(SDᵢ² + SDⱼ² − 2ρ·SDᵢ·SDⱼ) in quadrature, labelled a lower bound. Estimate ρ from Bug Hunt's public run-level data (per-task agreement across a configuration's runs), publishing measured values beside assumed grid points; where only one run exists, keep the assumption and say so. AA's per-task cost, token and time reporting makes at least a cross-task dispersion computable today. [artificialanalysis](https://artificialanalysis.ai/methodology/coding-agents-benchmarking)
3. **One-sided missing-telemetry cost sensitivity** for the Coding Agent Index component (impute at row max and cohort P75 per-task cost; report value-rank changes). This closes the systematic-low bias risk in O27 without changing the scored value.
4. **Numeric claim-scope coverage.** A build-generated sentence per ranking: "N of M cohort configurations ranked; excluded frontier-family primaries: …" — implementable from the existing cohort and listed-indicative artifacts.
5. **Bootstrap CIs on frozen bar levels** (order-statistic uncertainty at n = 9 and n = 20), published beside bar answers, never changing labels or the frozen values.
