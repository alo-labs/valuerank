**Medium**

1. **The 90% scenario-label guarantee is per event, but labels are consumed as a set.** E77 certifies each event with per-look error δ = 0.05/16; the draft states the bound is "per event, not simultaneous across the family" and E198a discloses non-correction across a bar's candidates. New argument beyond the ledger: a release certifies a label set (two bases × bars × top-k series × frontier events — plausibly dozens of events), so the expected number of wrongly certified labels scales with the family size F even though each individual certificate is honest; disclosure corrects neither the consumer's reading of the printed set nor the headline phrasing around it. Recommended change: rescale the error budget by the declared event family, δ = 0.05/(16·F) with F published in the release manifest — Clopper–Pearson in closed form makes this computationally free, and the E150 SciPy regression fixture transports unchanged.

2. **S1T draws are independent across models, so published rank/frontier shares and noise margins carry an unquantified directional bias.** A scenario redraws each row's leaves independently, yet cohort models face the same task sets, so their task-sampling errors are positively correlated via shared task difficulty; under independence, Var(score_i − score_j) is overstated, which widens every pairwise ordering share and pads the O42 separability threshold and the O44 noise margin in one direction (conservative, but by an unknown amount, and it distorts top-k and frontier event shares that consumers read as comparative evidence). The O42 correlation grid (0/0.3/0.6) already exists for the noise bands, and E309 shows the draft's pattern for a correlation stress; recommended change: register a shared-task-difficulty factor branch inside S1T (one common per-benchmark factor per scenario, correlation grid as in O42) so the published separability figure and top-3 shares carry the same sensitivity treatment, not just the pointwise threshold. This needs no new public data — it is an assumption grid, exactly like the Bug Hunt covariance stress.

3. **The Plan headline scalar convention is asymmetric across evidence classes.** Under E74 a set-identified M_W ∈ [L, U] is scored at L (conservative), with the upper-bound rank sensitivity published beside it; but a row with no identified M_W is scored at M_observed, an O88 same-model figure, or a flagged owner assumption — none of which is forced to the conservative end of what is admissible for that row. Today no Plan route has an identified M_W, so this is latent, but the day the first identified row appears, the headline will compare one row at its worst case against others at their point figures, and rank inversions between evidence classes become possible with no sensitivity published that symmetrically scores unidentified rows at their conservative admissible end. Recommended change: define the headline convention once per evidence class ("most conservative admissible scalar from that class's typed record") and extend the already-published upper-bound common-panel rank sensitivity to a both-ends sensitivity for every row class, so comparability is by construction rather than by coincidence. This does not touch O3 (full-utilisation Value Multiple) or the O19 ban on analyst-assumed allowances in interval outputs; it only equalises the scalar convention across classes that are already scored.

4. **Roughly two-thirds to four-fifths of nominal quality weight rides on one publisher, with no standing release-level flag.** The leave-AA-out branch is "not identifiable under the coverage rule" because independent leaves hold only 34% (max-effort) and 22% (AI Coding Daily) of nominal weight — meaning the S0 displayed scores consumers see are 66% and 78% defined by AA-run leaves. The numbers are computed (they drive the branch register) but are not printed beside the headline ranking, and E62's matched-panel statistics exist without a prominence decision. Recommended change: print the "AA-run nominal weight share" per ranking beside the headline (mechanically free — it is already evaluated), and register an independent-source coverage target with the O52/O53 set-selection criterion recording its effect on this share. This is not an "Owner decision challenge" to O25/O52; it is a disclosure and goal-tracking addition on top of them.

## 2. Methodology design recommendations

In priority order:

1. **Family-wise certification budget.** Keep E77's closed-form sequential rule; set per-look error δ = 0.05/(16·F_release) where F_release is the count of events eligible for the 90% certification in the release manifest (bases both, all bars, all top-k series, frontier events). Publish F_release, δ, and the certificate fields it already records. Properties: preserves per-event validity; bounds the probability of any wrong certification in the label set (union bound) at ≤ 0.05; costs nothing computationally and no public data.

2. **Dependence stress branch for S1T (shared-task factor).** Register branch S1T-C: within each scenario, draw one common latent task-difficulty factor z_b per benchmark and correlate rows' leaf deviations as Δ_z,ib = √(1−ρ)·ε_ib + √ρ·z_b, grid ρ ∈ {0, 0.3, 0.6} (matching O42's published grid and E276's realisation: the two rankings' τ_b). Publish, per event family, the share range across the grid beside the primary independent draw. Expected consequence: separability thresholds and top-k shares that consumers can read as bracketed by a defensible dependence assumption rather than silently assuming ρ = 0.

3. **One scalar-convention law for the Plan headline.** Headline multiple per row = the most conservative admissible scalar of its typed record class: identified M_W → L (E74 as-is); measured M_observed with no transport identification → M_observed (typed "measured-workload figure, untransported", already E12/E166); owner assumption → assumption as-is (O16 flag). Publish the common-panel rank table under both-ends scoring (identified rows at U, plus any admissible bounds for the other classes where they exist) so evidence-class asymmetry is visible rather than latent. No interval outputs are touched; O25's protection of the published record is untouched since this governs a display convention the draft already treats as an assumption.

4. **Source-share and dependence disclosure at headline level.** Print next to each ranking's headline: (a) AA-run nominal weight share (66%/78% today, from the E146 register), (b) the E62 matched-panel statistics for identical scores on independent sources, (c) one line recording whether the release's O52 set-selection improved or worsened independent coverage. All three quantities are already computed or trivially derivable from existing registers.

5. **Uncertainty object completeness at the summary layer.** Add to each per-leaf kernel object `draw_sd_realised` and `summary_sd`, with the lint extended so any consistency claim about noise margins cites which one it uses (resolves Medium 5/low-priority ambiguity in §1 created by E353; zero model change).

6. **Task-count capture gate.** Extend the O36/O37 capture checks: each S1T leaf's n must equal the task count displayed on the captured board for the exact benchmark version named in the registry (would have caught the 100-vs-132 question automatically, ).
