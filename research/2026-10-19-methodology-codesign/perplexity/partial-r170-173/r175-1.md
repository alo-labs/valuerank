## 1. Findings by severity

**Critical**

**High**

**Medium**

- **The near rule's cost leg has no stated precision basis, and the near-gap edge diagnostic covers only the Index dimension.** The cohort is "rounded Index within 3 points of the frontier's best at equal or lower cost," with the gap pinned to AA's plotted (rounded) Index and an edge diagnostic published for configurations one rounded point either side of the boundary . E286's edge diagnostic discloses Index-rounding boundary cases, but nothing in part 1 or 2 states whether the "at equal or lower cost" comparison uses AA's exact cost field (which the registry captures ) or the rounded tooltip cost. If rounded, a configuration whose cost sits within one cost-rounding step of a frontier point's cost can flip which frontier point is the "best at equal or lower cost," and hence its near-gap membership, with no diagnostic covering that dimension. This hurts the objective because cohort membership is the gateway to ranking, anchors, bars and every claim. Change: state in the cohort section that the cost comparison uses the exact captured cost field (or the rounded value, if so); if rounded, extend the edge diagnostic to the cost dimension (configurations within one cost-rounding step of a qualifying frontier point) and add a "membership change within display precision" flag to the entrant/exit diff so a rounding artifact is never read as a real cohort move.
- **The objective asks a model-level question, but no output names a family's best ranked configuration.** The objective is "which frontier AI model is actually lowest cost for the value it delivers," yet every table and claim is configuration-level by design (E78), families have up to several ranked efforts, and O143 names unevaluated cheaper siblings without ever naming the family's best *ranked* option . A buyer who thinks in models must reconstruct the rollup from per-row output. This is distinct from the rejected sibling-evidence diagnostic (which was about transferring evidence) — the rollup uses only already-ranked rows and adds no evidence. Change: publish a per-family rollup beside each leading ranking: each family's ranked configurations in value order within that ranking and basis, the family-best flagged, labelled diagnostic (no label, no claim, no cross-ranking comparison), sourced entirely from existing scores.json rows.

The bracket is therefore asymmetric against the direction the draft itself names as possible. Change: add a ρ = −0.3 column to the grid — zero new evidence, same machinery.
- **E316's scale correction uses one pooled mean offset.** Cross-source offsets are pooled over the matched panel (FrontierCode: τ_b 0.91 on 26 configurations, −1.5 mean, up to 7.7 apart) ; a single additive offset mis-corrects the extremes if the offset varies with configuration strength. Change: where the matched panel supports it under E180's minimum-panel convention, publish a two-stratum (above/below panel median quality) offset as a second sensitivity beside the pooled one. Diagnostic only, so low priority.
- **Headline coverage counts.** Part 2 publishes ranked/listed/excluded counts, but the headline output itself does not state how much of the cohort it covers (9 of 37 ranked in the leading ranking; 12 excluded under O38) . O172's common-leaf answer mitigates the substance; a one-line coverage sentence in each leading headline (ranked / listed / excluded, both bases, linking the O38 list) would close the presentation gap at no cost.

## 2. Methodology design recommendations

Prioritised, all implementable from public data refreshable per release:

1. **Family-best rollup diagnostic (per leading ranking, per basis).** For each family (E193 AA model identity), take its ranked rows in that ranking, sort by value score, flag the family-best, and print the row count; on the Plan basis, the family's best plan row. Data source: existing value tables; no new evidence, no labels, no cross-ranking comparison. This directly serves the objective's model-level noun without touching E78's configuration language (rows stay configurations; the rollup is an index over them).
2. **Near-rule cost-basis specification plus cost-dimension edge diagnostic** (Medium finding 1): one sentence in the cohort section fixing the cost leg to the exact captured cost field; if rounded is retained, publish configurations within one cost-rounding step of a qualifying frontier point alongside the existing ±1 Index-point diagnostic, and flag entrant/exit diffs attributable to display precision.
3. **Common-leaf listed-beside treatment**: extend E259 (missing leaves + indicative value, "not ranked, not comparable") to the common-leaf diagnostic ranking's 4 uncovered configurations.
4. **Grid completion**: add ρ = −0.3 to the separability correlation grid, completing the bracket the draft's own caveat implies.
5. **Stratified cross-source offset sensitivity** for E316, second to the pooled offset, only where the matched panel meets E180 minimums — bounds the single-offset assumption behind the bar-results-without-fills sensitivity.
