## Known limitations

Full-utilisation Plan cost overstates value for light users (workday diagnostic shown); Plan rows of providers with no authorised or admitted route are priced at API cost (O72; today 2 of the max-effort ranking's 27 plan rows, DeepSeek V4.1 Flash 1017 (max) and Gemini 4 Argon (high), and 3 of the AI Coding Daily ranking's 51, DeepSeek V4.1 Flash 1017 (max), Gemini 4 Argon (high) and Kimi K3.1 Pro), so the Plan order mixes route availability with value; and most plan rows rest on a route flagged possibly superseded or expired (21 of 27 and 44 of 51), and some on a measurement taken inside an acknowledged accounting-fault window that no user report pair has yet replaced (3 and 8; O91, O92); the Value Multiple values only the API-equivalent consumption of the measured workload, so plan features outside it (chat, image generation, other surfaces, pools shared with them) are not valued; AA cost uses AA's token mix and cache protocol; Terminal-Bench work is priced in two executions; Bug Hunt covers two repositories; Bug Hunt, AI Coding Daily and a tbench.ai gap fill measure model+harness stacks, and AI Coding Daily's harness differs by model; suite is primarily English text; ITBench-AA remains pending until complete exact-variant cost evidence covers two-thirds of a ranking's cohort rows jointly with the admitted components (E95, E101), and the Coding Agent Index v2.0 is pending in the AI Coding Daily ranking (today 3 of 16, E254), so that ranking's cost basket holds no coding-agent component unless FrontierCode's own chart total, which stands in for the index while it is pending (owner decision O116, 2026-10-29), is admitted (today it covers 5 of 16, so it is not); Terminal-Bench 4.0's Index run is its one agentic coding evaluation, and its coding share is far lower than the max-effort ranking's.
