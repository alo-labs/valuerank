- **Interval decision procedure (E40, amended by E43).** Interval labels are decided by deterministic, decision-specific feasibility problems over Θ, never from scenario draws. Primitive domains have a box enclosure (per-row input boxes and a box of declared shared factors, e.g. a common price list or a donor multiple shared by several rows); Θ itself is the constrained subset defined by E73, and a product-box representation may replace it only under a decision-specific equivalence proof (E169). **Constrained evidence model (E73)**: the primitive-variable constraint graph Θ = {v : ℓ ≤ v ≤ u, h(v) = 0, g(v) ≤ 0} is authoritative; costs, quality, capacities and multiples are derived quantities of v (an identity such as API-valued capacity = λ × C_API survives uncertainty propagation). A box reduction is used only with a decision-specific equivalence proof; otherwise the box is an outer enclosure for pruning, and every witness is certified against the original constraints (release fixture: an enclosing box containing a favourable state the original constraints exclude must never return a certified possible membership). **Separability condition (E89)**: with no shared factor **and no row-local coupling** — each row's C and Q depend on disjoint primitives with no joint constraint, so the row's feasible set is the product of its C and Q ranges — each label is decided exactly by monotone extremes (Q is linear in leaf values; basket cost is monotone in component costs; each row's inputs move only its own C and Q): e.g. possible-frontier membership of i is established by setting i to its best corner and every j to its worst. A row-local primitive or constraint that enters both C_i and Q_i is a coupled variable and is branched over like a shared factor; a constraint class the solver does not support returns unresolved (release test: i with C_i = 1 + t, Q_i = t, t ∈ [0, 1]; j with C = 1, Q = 0.5; k with C = 1.5, Q = 1 — i is dominated for every t although its box corner (1, 1) is undominated, so the solver must return disproved and never a possible membership). In v1 every row's C and Q come from distinct published records and Bug Hunt's two scale maxima are fixed release constants (E346), not primitives, so the condition holds and is asserted per release. **Shared price factors (E276)**: two rows can still share an uncertain cost factor, through a superseded tariff's hull on one model's price list (two efforts of one model, E183) or one registered pricing omission (O94, O98) — tariffs in force are published constants, not uncertain factors; such a factor moves the rows' costs together, never against each other. A row carrying one is a blocker that competes and never earns a label (E183, E186, O94), and the factor covers every effort of its model, so a candidate never shares it; the possible-frontier and bar tests set every competitor at one common extreme (all at their worst corners, or all at their best), a state the shared factor permits, and the definite test moves one competitor at a time, so the per-row boxes give the same answers as the joint constraint; the one cross-row factor the Plan basis can create, a donor multiple shared by several configurations, is checked by the build: when two configurations among the rows a decision reads (its Plan candidates, competitors and the blockers B_W of U_W = R_W ∪ B_W, E313 on reviewer 83) rest on one donor multiple identified only as a range, the Plan interval outputs are unresolved, with the shared donor named, and never computed by corners (E273). With shared factors or row-local coupling, labels are decided by **certified interval branch-and-bound** over the shared-factor box: on each sub-box, interval bounds either certify the condition for every point (witness), refute it for every point (prune), or the sub-box is split, up to a published depth; a sub-box still undecided at that depth returns **unresolved**. Endpoint search alone is not sufficient (release test: competitors with Q_j = 2t and Q_k = 2(1 − t), C_j = C_k = 0, and i with C_i = 1, Q_i = 1.2: i is a possible-frontier member via the interior witness t = 0.5). Possible-frontier membership solves, in one common θ, for every j ≠ i: C_j(θ) > C_i(θ) ∨ Q_j(θ) < Q_i(θ) ∨ [C_j(θ) = C_i(θ) ∧ Q_j(θ) = Q_i(θ)]; definite membership is disproved by one θ and one dominating j; strict inequalities are decided exactly, never by tolerance alone. Every returned witness is re-checked against the original equations and shared constraints. The monotone-corner shortcut is used only for decisions with a documented corner-reduction proof; dependencies are compiled from the complete decision equations, so a varying reference quality Q_r is a shared variable for every qualification condition even when all row inputs are independent (E50; a frozen bar level is a constant and adds no shared variable, but the rule binds any registered varying reference): bar decisions partition at qualification breakpoints (exact enumeration for affine one-dimensional thresholds) or use the certified branch-and-bound (regression test: i with C = 1, Q = 5; j with C = 0, Q = 4; Q_r ∈ [0, 10] — i ∈ K_r via the interior witness Q_r = 4.5, which neither endpoint shows). Feasible witnesses and infeasibility certificates have separate proof obligations, and numerical bounds may not discard feasible points through floating-point error. Statuses: certified / disproved / unresolved / unevaluable, with solver status, depth and witness (or counterexample) stored; an unresolved solve is never shown as certified. **Certification grammar (E108)**: each decision is compiled into (1) primitive domains and the original constraints, (2) a reduced problem obtained only by documented, equivalence-preserving substitutions (definitional equalities are eliminated by substitution wherever possible) and (3) a certificate checked independently against the original problem. Supported v1 classes: boxes, affine constraints decided in exact rational arithmetic on the published decimal inputs, separable monotone transforms and the documented corner reductions; a nonlinear equality is supported only with a validated existence certificate (e.g. a sign change of a continuous univariate function evaluated exactly at rational endpoints); every other class returns unresolved, and a small numerical residual is never a feasibility certificate (fixtures: x² = 2 with x ∈ [1, 2] is certified feasible without a rational witness; x² = 2 with x ∈ [1, 1.4] is certified infeasible; an approximate point with residual 10⁻⁶ certifies nothing). **Feasibility prerequisite (E79)**: before any decision, the decision's full constraint component (all connected shared variables and identities) must have a certified feasible witness checked against the original constraints; certified infeasible → "inconsistent evidence", no frontier or bar labels for the affected output, release-blocking for that output with the conflicting records listed; feasibility unresolved → "unresolved", no confirmed or definite label (fixtures: individually valid intervals whose shared identity has an empty intersection; a feasible outer box whose original constrained set is empty — neither may produce a confirmed, definite or certified-possible result).

- **Robustness outputs (E13, amended by O22).** Separate, named columns: (1) displayed-score rank sensitivity (scalar displayed value score); (2) full-composite scenario-rank sensitivity (scalar V_i(θ) = 0.25 S_C(c_i(θ)) + 0.75 Q_i(θ)); (3) branch evaluability and exclusion reasons, with retained quality weight shown before any rank statistic. - **Cohort rule (executable).** F(c) = best rounded Index among rendered-frontier configurations with cost ≤ c. A configuration is near-frontier when its rounded Index ≥ F(c) − 3. **Membership (O51, O145)**: the plotted cohort P_t is the configurations on the rendered frontier plus those with rounded Index ≥ F(c) − 3, each its own row; the retained set is T_t = P_(t−1) ∖ P_t, the previous release's plotted cohort (not its retained rows) less this one's, each once per exit (E306); the cohort is C_t = P_t ∪ T_t, and no other configuration enters it (E310, on reviewer 82; capture, roster, search and ranking all read C_t, the frontier-only diagnostics P_t). A point cheaper than every rendered-frontier point has no F(c) and is not near-frontier; while E204 holds no such point exists, so this is a defensive default. **Left of the rendered line (E204)**: AA's line is used as observed, so the build checks that no plotted point lies left of the path's first vertex (by chart x-coordinate, tolerance 0.5 px). If one does, the build stops and names it until the owner records a dated, reasoned decision for it, so such a point can never drop out silently. Today none does: on the capture the first vertex, GPT-6 Luna (low) at $9.09, costs the same as the cheapest of the 82 plotted points ($9.09), and the build fails otherwise. Every near point publishes its cost ratio to the frontier for information only: its total Index cost divided by the lowest cost of a rendered-frontier point whose plotted (tooltip, rounded) Index is at least its own; the ratio never gates inclusion (AGENTS.md). A near-frontier family is deferred only by a dated, reasoned roster decision recorded in the reconciliation inventory, and it stays listed there. Ties go to the lower cost, then the name. The family key is the plotted model name with its trailing parenthesised qualifier (effort and "with fallback") removed. It must equal the catalog model's display name, and the build checks this.
- **Omniscience counts (O28).** From AA counts (c correct, p partial, i incorrect, a not attempted; T = c + p + i + a): I = 100 (c − i) / T and z = (I + 100)/2. Test vectors: c=60, p=0, i=10, a=30 → I = 50, z = 75; monotonicity fixtures — (98, 0, 1, 1) → z = 98.5 and (99, 0, 1, 0) → z = 99 (an abstention turned correct raises z); (60, 0, 10, 30) → (60, 0, 9, 31) raises z (a wrong answer turned abstention); all-abstention → 50. The reconstruction I = 100 [A − h (1 − A)] from AA's accuracy A = c/T (correct answers over all T questions, abstentions included) and conditional hallucination rate h = i/(T − c) (wrong answers over the questions not answered correctly; partial answers enter only T; with every question correct, c = T, h is undefined and the reconstruction reads I = 100 directly, reviewer 99) is tested against AA's published index each release, and the build stops on a residual above 0.05 index points, half AA's displayed precision; the accuracy and hallucination rates are captured at AA's full stored precision, not as displayed, so only the index's rounding enters, and a capture whose rates were rounded would add their propagated half-widths to the tolerance (reviewer 81); the vector (60, 0, 10, 30) gives A = 0.6, h = 0.25 and I = 50, as the counts do.
