## 2. Methodology design recommendations

Priority order; all are small and implementable from existing data.

1. **A publication contract for the second ranking (M1).** Choose parity or an explicit scope sentence, and make it checkable: a table in the draft (output, document, rankings covered) that E265's check reads, so a pointer such as "printed for each ranking in scores.md" fails the test when a ranking's section is missing. The check already parses the draft for pointers to these four documents; extending it from "figures" to "sections" removes the class the way E265 removed stale figures.
2. **Generate every ranking-dependent sentence from the ranking's own Facts.** The basket description (site and README), the coding and unrewarded shares, the variance-allocation sentence (E196, for both rankings and for the above-100% case), the machine-readable file list and the calibration-unavailable line all have per-ranking data already; the defects above are leading-ranking text reached by the second ranking.
3. **Define "assumption-grade route" once (L4).** Owner-named transfer or O46 quota ceiling, graded "assumption" by the build; use it in E106 (new case 2b), E166's amount types ("assumed consumption; donor named, or provider-derived ceiling"), comparator key 2, E242's † footnote and the published labels.
4. **Keep one sentence per rule.** L3, L6 and the I46 L1 duplicate came from the same sentence existing in the draft, `emit_docs.py` and `plan_cost_routes.json`. Where methodology.md restates a rule, generate it from the same source as the draft's placeholder, or cite the rule.
5. **Print the panel size and excluded rows in the lead-in of every scenario table** (E96, L7), and, as I46 suggested, publish a transfers-off Plan panel as "not informative: no measured route" when it holds only API-fallback rows (the AI Coding Daily ranking's two-row panel).
6. **Carry-overs, not repeated as findings:** generate the hand-written "missing leaves today" and "report route" sentences from `leaf_evidence.json` and the route registry (I46 L5); the headline bars of the max-effort ranking (64.3 and 65.0) are 0.7 points apart against a 3.8-point noise margin (recorded for the owner report at I44).
