2. Methodology design recommendations

Split every order by workload hash. For each anchor object, rank only rows scored on that object. Separability uses adjacent pairs inside the object, with the existing 1.96 × √(SD_i² + SD_j²) rule at ρ = 0, cost not drawn. Cross-object pairs are a count, not a test. Bar reach and confirmedQualifierN already use R_W. Make the ordinal table match them.

Add one claim gate, codingCostAligned, computed from the existing basket-readiness shares. Let s_code be the median expenditure share of the Coding Agent Index, if admitted, plus Terminal-Bench 4.0 and SciCode. Let q_code be the O122 coding-specific quality share. Labels require s_code ≥ q_code and FullCost. Otherwise the ranking stays scored and diagnostic, as the common-leaf ranking already is. No new data source.

Register a v5 migration table before the next capture. Rows: old chart identity to v5 chart identity. Cohort rule unchanged. Cost identity: replace the ten-evaluation sum with the nine v5 evaluations only after the reconstruction test passes at 10⁻⁶. Leaves that disappear from model pages are gaps, not zeros. FrontierCode 1.1 remains the leaf until an owner admits 2.0. Anchors do not move until that workload migration has two valuation-eligible references.

Fallback rule, using fields already captured. Point cost stays AA’s mean.costUsd × 290. Interval eligibility fails when blocked plus fallback attempts are positive. Blocker domain is [C, ∞) until a public per-attempt split exists, then [C, C × (attempts / attempts without fallback tokens)] only if that split prices the contestant’s tokens alone. This is the O94 pattern, not a new score.

LiveBench split, if the owner accepts finding 6. Coding weight 15 × 3.5/9. Remainder 15 × 5.5/9 moves into general professional work beside GDPval and AutomationBench. The build already stops on a LiveBench record whose weights are not the pinned nine. Reuse that check. Do not reopen the 60% group total until the owner does.

Plan page, without withholding scores. Three blocks, same anchors: measured routes, owner-assumption routes, API fallback. One value order only inside a block. The cross-block order is labelled assumption arithmetic. This is not the rejected proposal to drop unidentified scores.
