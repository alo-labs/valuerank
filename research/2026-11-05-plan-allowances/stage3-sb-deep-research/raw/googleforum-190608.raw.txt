Hi @Muhammed_Alpler,

Welcome to the Forum,

Thank you for the detailed analysis. Antigravity quota isn't based on public API prices. Each model's quota is set based on available capacity and the amount of work the agent does, which also depends on the thinking level, how many tokens a task uses and how much of the context can be reused. That means the same task can use a different share of quota on different models. 

You can see per-model usage on the Settings page, which can help you determine the most quota-efficient model to use for your specific workflows.
