Muse Ember

Meta introduced Muse Ember, a model designed for repeated agent tasks such as tool calls, coding subtasks, routing, extraction, and long-document parsing. Meta says it is available through the Meta Model API, with a 1M-token context window and native text, image, audio, and video understanding.

What changed

Meta introduced Muse Ember as its smallest and most efficient model, designed for repeated agent tasks including tool calls, coding subtasks, routing, extraction, and long-document parsing. Meta says it supports a 1M-token context window and native text, image, audio, and video understanding. The announcement does not frame this as a numbered upgrade from a specific predecessor.

Access and availability

Meta says Muse Ember is available on the Meta Model API and in Muse Code. The published model identifier is muse-ember-1.0. Meta lists API prices of $0.10 per million input tokens and $0.50 per million output tokens.

What you can build

Try it on a bounded, repeatable workflow and check both the output quality and total token use against your current model before routing larger workloads.

Limitations

The announcement does not specify regional availability, rate limits, or a detailed modality-specific API interface. Performance comparisons and capability claims on the page are Meta's or its named partners' evaluations, not independent testing.
