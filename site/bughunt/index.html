Bug Hunt Bench: cost vs bugs fixed, Pareto frontier

Score = planted bugs fixed + genuine unplanted bugs fixed, ValueRank's rescoring (the board itself scores planted bugs only and lists unplanted fixes separately); per-run means where a row averages several runs. Cost is the board's per-run figure (list-rate estimate, bill or floor), log scale.

The frontier joins the configurations that no other configuration beats on both cost and score: nothing cheaper scores higher.
