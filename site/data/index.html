Open data

Download the data

Every table on this site is published as a static JSON file you can fetch directly. Files are regenerated with each release and keep stable field names.

Files

  • /data/rankings.json

    Every roster model with v3 value scores, ranks, basket cost and evidence on both bases.

    Schema

    {version, publishDate, observedAt, methodologyVersion, basketVersion, bases, defaultBasis, costWeightPct, exchangeRate, planExploratory, modelInclusion, dimensions, categories, models, planModels, picks}

  • /data/models/<slug>.json

    One document per roster model with every quality leaf, its source, the cost basket, plan routes, scenario shares and history.

    Schema

    {slug, name, developer, aaUrl, aaVariant, selectedPage, summary, dimensions, cost, plans, scenarios, intervals, history, frontier}

  • /data/plans.json

    Subscription routes, their evidence and every candidate's API and Plan basket cost.

    Schema

    {asOf, policy, identificationYield, routes, candidates, workedExample}

  • /data/benchmarks.json

    Quality-leaf sources and coverage, the admitted cost basket and the Artificial Analysis frontier.

    Schema

    {sources, basket, qualitySourceShares, frontier}

  • /data/benchmarks/terminal-bench-4.json

    Terminal-Bench 4.0 official rows, provider claims and cohort mapping.

    Schema

    {schemaVersion, version, observedAt, source, rowN, rowsWithoutCostN, cohortN, matchedN, missingModels, rankingAvailableN, rankingMissingModels, providerClaimN, providerClaims, providerClaimPolicy, rows, cohortRows, frontierCount, cohortMapping}

  • /data/changelog.json

    Versions, newest first, with recorded ranks and rank changes between consecutive releases.

    Schema

    {versions}

  • /data/livebench.json

    Matched LiveBench rows (no longer scored; owner decision O26), with cost per successful task.

    Schema

    {release, observedAt, rows}

Using the data

Numbers are JSON numbers or null; a null means no eligible value and is never zero. Every value carries an evidence grade. Cite the version in the changelog with the observation date.

ValueRank v3.0.0
