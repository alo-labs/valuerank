Methodology
How scores are calculated from each model’s available dimensions, with per-model weight renormalization and explicit coverage provenance.

Scoring Formula

Score = ((n − rank) / (n − 1)) × 100

For each retained dimension, models with an observed result are ranked within that dimension; rank 1 maps to 100 points and the last observed rank maps to 0, with ties receiving the average tied rank. Each model’s available dimension priorities are renormalized to calculate its score. v1.9.6 reports priority coverage and missing metrics and does not impute missing values.

The final ValueRank score is a weighted sum across 16 retained dimensions. Cost weight: 18.94% (slider-adjustable). Bug Hunt Bench contributes 15.15% and DeepSWE v1.1 contributes 18.94%. API Costs uses AA total evaluation cost; Plan Costs divides the same value by the highest eligible subscription Value Multiple.

Key Design Choices

Rank-based (not raw-score-based): Prevents any single benchmark from dominating due to scale differences. GPQA percentages, DeepSWE pass rates, and token-per-second speed figures are not directly comparable on raw values; ranks are.
Missing-metric handling: Each model’s observed retained metrics contribute to its score, with available priorities renormalized; missing values remain unavailable and are shown in the matrix and coverage note. Exact benchmark-version and evaluated-model matches are required; the full source roster contains 28 candidates.
SEAL CI band (±2–3 pts): Due to benchmark variance, scores within 2–3 pts should be treated as statistically tied. Rankings within this band are effectively co-ranked.
Quality sub-score:The weighted average of each model’s available non-cost dimensions, renormalized to 100%. It represents benchmark capability without the cost penalty.

FAQ
Frequently Asked Questions
Common questions about how ValueRank works, what the scores mean, and how to interpret results.
Each model’s score is the weighted average of its available normalized dimensions; available priorities are renormalized per model and priority coverage plus missing metrics are reported beside the score. Dimension scores use ((n − rank) / (n − 1)) × 100 over models with an observation for that dimension; ties receive average rank. Missing values are not imputed. AA-Omniscience is represented as Non-Hallucination Rate, where higher is better. API Costs uses AA total evaluation cost; Plan Costs divides the same value by the highest eligible subscription Value Multiple.
Cost has a 18.94% weight in the primary score. The API Costs basis uses AA total evaluation cost; Plan Costs divides that same cost by the highest eligible subscription Value Multiple. Both views use the same benchmark suite and lower cost ranks better.
⊘ marks a missing observation for that model and dimension. The score excludes missing metrics and renormalizes the available priorities per model; the table reports priority coverage and missing metrics beside each partial score.
The overall Score uses the model’s available retained dimensions, including Bug Hunt and DeepSWE v1.1 where observed, with cost at 18.94% by default. Quality Score renormalizes the available non-cost dimensions to 100%, showing benchmark performance without the cost weight.
ValueRank reflects the selected benchmarks and their weights, including DeepSWE v1.1 and Bug Hunt in the main rank; it is not a general model-capability verdict. The current overall leader is GPT-5.6 Sol (#1); the quality leader is GPT-6 Astra (#1). API Costs and Plan Costs are presented as separate cost views.
The Pareto frontier contains models that are not dominated on both quality and cost under the selected cost basis. The Pareto chart updates when you switch between API Costs and Plan Costs.
Prior-version scores are not directly comparable. The eligible models, benchmark versions, dimensions, and weights can change, shifting rank-normalized scores. Use the version history table for rank movement and each release record for its own score values.
ValueRank is refreshed when primary benchmark results or cost inputs materially change. v1.9.6 reconciles the AA Intelligence Index score-versus-total-benchmark-cost frontier, uses configuration-specific DeepSWE v1.1 results, and includes observed Bug Hunt results in the per-model available-dimension score.
