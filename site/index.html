Methodology
How scores are calculated across 12 current zero-gap dimensions, with explicit cost construction and coverage provenance.

Scoring Formula

Score = ((n − rank) / (n − 1)) × 100

For each of 12 retained dimensions, the 13 exact-overlap models are ranked from 1–13. Rank 1 maps to 100 points and rank 13 to 0; ties receive the average tied rank. v1.9.5 excludes incomplete dimensions and does not fill missing values.

The final ValueRank score is a weighted sum across 12 retained dimensions. Cost weight: 22.32% (slider-adjustable). Bug Hunt Bench contributes 17.86% and DeepSWE v1.1 contributes 22.32%. API Costs uses AA total evaluation cost; Plan Costs divides the same value by the highest eligible subscription Value Multiple.

Key Design Choices

Rank-based (not raw-score-based): Prevents any single benchmark from dominating due to scale differences. GPQA percentages, DeepSWE pass rates, and token-per-second speed figures are not directly comparable on raw values; ranks are.
Zero-gap benchmark rule: If any of the 13 primary-cohort models is missing from a benchmark, that dimension is excluded from the composite. Exact benchmark-version and evaluated-model matches are required; the full source roster contains 27 candidates.
SEAL CI band (±2–3 pts): Due to benchmark variance, scores within 2–3 pts should be treated as statistically tied. Rankings within this band are effectively co-ranked.
Quality sub-score:The weighted sum of the 11 non-cost dimensions, renormalized to 100%. It represents benchmark capability without the cost penalty.

FAQ
Frequently Asked Questions
Common questions about how ValueRank works, what the scores mean, and how to interpret results.
Each model’s score is a weighted average of 12 normalized dimension scores across the 13-model exact-overlap cohort. Each dimension score uses ((n − rank) / (n − 1)) × 100, with n = 13; ties receive average rank. Incomplete dimensions are excluded rather than imputed. AA-Omniscience is represented as Non-Hallucination Rate, where higher is better. API Costs uses AA total evaluation cost; Plan Costs divides the same value by the highest eligible subscription Value Multiple.
Cost has a 22.32% weight in the primary score. The API Costs basis uses AA total evaluation cost; Plan Costs divides that same cost by the highest eligible subscription Value Multiple. Both views use the same benchmark suite and lower cost ranks better.
In historical ValueRank versions, ⊘ marked a genuine benchmark data gap. In v1.9.5, incomplete dimensions are excluded from the composite, so every ranked model has full coverage across the retained dimensions.
The overall Score includes all 12 retained dimensions, including Bug Hunt and DeepSWE v1.1, with cost at 22.32% by default. Quality Score renormalizes the 11 non-cost dimensions to 100%, showing benchmark performance without the cost weight.
ValueRank reflects the selected benchmarks and their weights, including DeepSWE v1.1 and Bug Hunt in the main rank; it is not a general model-capability verdict. The current overall leader is GPT-5.6 Sol (#1); the quality leader is GPT-6 Astra (#1). API Costs and Plan Costs are presented as separate cost views.
The Pareto frontier contains models that are not dominated on both quality and cost under the selected cost basis. The Pareto chart updates when you switch between API Costs and Plan Costs.
Prior-version scores are not directly comparable. The eligible models, benchmark versions, dimensions, and weights can change, shifting rank-normalized scores. Use the version history table for rank movement and each release record for its own score values.
ValueRank is refreshed when primary benchmark results or cost inputs materially change. v1.9.5 uses AA Coding Agent Index v1.5 DeepSWE v1.1 results, includes Bug Hunt in the primary score, and ranks 13 exact-overlap models across 12 zero-gap dimensions.
