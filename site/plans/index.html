Plans: what a subscription is really worth

A flat monthly fee can be a much cheaper way to use a model than paying per token. ValueRank converts that into one number, USD per Intelligence Index point, so a plan model and an API-only model can be ranked together.

How the number is built

  1. API cost of the benchmark. Artificial Analysis reports what it cost to run the whole Intelligence Index on the model at API rates.
  2. Divide by the value multiple. The value multiple is how many dollars of API-priced work one subscription dollar buys, taken from measured usage.
  3. Divide by the Index score. The result is plan dollars per Intelligence Index point.
Worked example of the plan cost calculation

What this does and does not claim. It estimates the price of one benchmark run on a plan, not what your own usage will cost. Provisional assumptions are flagged on every route.

Evidence grades

  • Owner-measured Measured by the benchmark owner or in a controlled account measurement.
  • Provider claim Published by the model provider for the exact benchmark version and evaluated variant.
  • Modelled Owner estimate or projection anchored to a measurement.
  • Assumption Explicitly authorised assumption with no measurement.
  • Missing No eligible value; excluded from the score and the score is renormalised.
