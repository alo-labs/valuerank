Plans: what a subscription is really worth

A flat monthly fee can be a much cheaper way to use a model than paying per token. ValueRank prices the same SDLC basket both ways: at API rates, and on a subscription by dividing that API cost by the plan's Value Multiple, so plan and API-only models can be ranked together.

How the number is built

  1. API cost of the basket. Artificial Analysis publishes what it cost to run each evaluation on the model at API rates. The SDLC basket adds up seven Intelligence Index evaluations and the Coding Agent Index.
  2. Divide by the Value Multiple. The Value Multiple is how many dollars of API-priced work one subscription dollar buys at full use of the plan. Each route says whether its multiple is a measured capacity, observed consumption or an owner-authorised transfer from another model.
  3. The result is the plan cost of one basket run. It is scored on a log scale against frozen anchors, like the API cost.
Worked example of the plan cost calculation
ModelAPI cost per basket runValue MultiplePlan cost per basket runRoute
Claude Opus 5.5 $9,989.15 58.90× $169.60 User-measured Claude Pro $20 · Opus 5.5
GPT-6.1 Sol $1,267.66 10.77× $117.68 User-measured ChatGPT Pro $500 · common GPT assumption

What this does and does not claim. It prices one run of the basket on a plan at full utilisation, not what your own usage will cost. Each Value Multiple was measured on its own workload; none is yet identified on the basket, so the Plan ranking is exploratory. Assumptions are flagged on every route.

Evidence grades

  • User-measured Measured by the benchmark owner or in a controlled account measurement.
  • Provider claim Published by the model provider for the exact benchmark version and evaluated variant.
  • Modelled Owner estimate or projection anchored to a measurement.
  • Assumption Explicitly authorised assumption with no measurement.
  • Missing No eligible value; excluded from the score and the score is renormalised.
