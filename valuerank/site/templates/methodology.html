How ValueRank scores a model

A configuration's score is its value: a cost score carries a fixed {{ num(page.costWeightPct, 0) }}% and benchmark quality the other {{ num(100 - page.costWeightPct, 0) }}%.{% set share = page.method.costVarianceShare %}{% if share.api is not none and share.plan is not none %} That weight is nominal: on the current panel, cost accounts for {{ num(100 * share.api, 0) }}% of the spread in API value and {{ num(100 * share.plan, 0) }}% in Plan value, because cost scores vary more across configurations than quality scores do.{% endif %} Cost is what it costs to run the SDLC basket once, scored on a log scale so cost ratios keep their size. Quality is the weighted mean of the benchmark leaves observed for that exact configuration: a missing leaf is left out and never filled in, and a configuration without a cost gets no value score.

Cost: the SDLC basket

The cost figure is the {{ m.costLabel }}: Artificial Analysis' published cost of running {{ m.basket.admitted | map(attribute="label") | join(", ") }} once at API rates ({{ m.basket.version }}).{% if m.basket.pending %} Pending capture: {{ m.basket.pending | map(attribute="label") | join(", ") }}.{% endif %} A configuration missing a component is scored on its own subset of the basket, flagged, and never compared as if it had run the whole basket.

The cost score is 100 × (ln cH − ln c) / (ln cH − ln cL), clipped to 0–100, against anchors frozen with anchor version {{ m.anchorVersion }}: API anchors {{ usd(m.anchors.api.low, 2) }} to {{ usd(m.anchors.api.high, 2) }} per basket run. At these anchors, doubling the cost costs {{ num(m.exchangeRate.api.valuePointsPerCostDoubling, 2) }} value points, which {{ num(m.exchangeRate.api.qualityPointsPerCostDoubling, 2) }} quality points offset.

On the Plan basis the basket's API cost is divided by the selected subscription route's Value Multiple at full utilisation; a configuration without an admitted route falls back to its API cost, flagged.{% if m.planExploratory %} No Value Multiple is yet identified on the basket itself, so the Plan ranking is labelled exploratory.{% endif %}

Worked example: {{ w.name }}

Cost takes its fixed {{ num(page.costWeightPct, 0) }}% share.
